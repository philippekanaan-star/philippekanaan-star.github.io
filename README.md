# Site MARSĀ

Site de presentation de MARSĀ - intelligence client pour editeurs SaaS B2B.

- index.html : landing FR (page principale)
- index-en.html : landing EN
- offres.html / offres-en.html : page Offres dediee (tarif publie, inclus, FAQ tarifaire)
- roi.html / roi-en.html : calculateur de ROI (cout du churn, gain, retour sur investissement)
- ancien-site.html / ancien-site-offres.html : archive de la version precedente du site (loya), conservee a une URL discrete
- v2.html / v2-en.html : redirection vers index.html / index-en.html (compatibilite anciens liens)

Fichiers statiques autonomes, sans dependance ni build. Publies via GitHub Pages.

Bascule de langue : lien FR/EN dans le menu, index.html <-> index-en.html, offres.html <-> offres-en.html, roi.html <-> roi-en.html (fichiers distincts, pas de parametre ?lang).

Reglages du formulaire de contact, en bas de index.html et index-en.html : CONTACT_EMAIL (destinataire) et FORM_ENDPOINT (vide = ouverture du client mail).

Tarification (depuis aout 2026) : 490 € HT par licence et par mois. Une licence = un utilisateur + 500 comptes suivis (licences facturees = max(utilisateurs, comptes / 500 arrondi au superieur)). Aucun frais de mise en service. Tarif unique, publie, sans palier Enterprise cache.

Identite : bleu #2b6ce0, sable #f5f1e7, encre #14150f. Nom de marque ecrit "MARSĀ" en majuscules dans les textes du site.
